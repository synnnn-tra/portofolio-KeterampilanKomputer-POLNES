## Pokok Bahasan dalam Video Presentasi
1. **Pembahasan Tugas 1 (Mail Merge):** Definisi, manfaat efisiensi waktu, 3 komponen utama (*Main Document*, *Data Source* Excel, *Merge Fields*), langkah menghubungkan data, serta solusi kendala umum.
2. **Pembahasan Tugas 2 (Microsoft Excel):** Pengenalan area kerja (*Workbook*, *Worksheet*, *Cell*, *Range*, *Formula Bar*), langkah pembuatan dan pemformatan tabel, penggunaan rumus dasar (`SUM`, `AVERAGE`, `MAX`, `MIN`, `COUNT`, `IF`), serta fitur analisis (*Sort*, *Filter*, *Conditional Formatting*, *Chart*).
3. **Integrasi Tugas 1 & Tugas 2:** Alur kerja administratif terpadu dari pengolahan data Excel hingga otomatisasi dokumen resmi di Word dan penyajian visual di PowerPoint.
