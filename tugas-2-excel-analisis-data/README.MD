# Tugas 2 — Analisis Data Penjualan Tiket Pesawat Terbang (1990–2000)

## Deskripsi Tugas
Mengolah tabel data penjualan tiket pesawat terbang pada **25 bandara/provinsi** di Indonesia untuk periode **1990 hingga 2000** menggunakan **Microsoft Excel**, dengan penambahan:
1. **1 Kolom Tambahan (`RATA-RATA KOTA/BANDARA`)** untuk menghitung rata-rata penjualan tiap bandara selama 11 tahun.
2. **1 Baris Tambahan (`RATA-RATA TAHUN`)** untuk menghitung rata-rata penjualan seluruh bandara pada setiap tahunnya.

## Rumus & Ringkasan Statistik
* **Rumus Rata-Rata Kota/Bandara (Kolom N):** `=AVERAGE(C6:M6)`
* **Rumus Rata-Rata Tahun (Baris 31):** `=AVERAGE(C6:C30)`
* **Rata-Rata Keseluruhan:** `564,47`
* **3 Bandara Tertinggi:** Jawa Tengah (`700,55`), Bali (`693,18`), Sumatera Barat (`679,82`)
